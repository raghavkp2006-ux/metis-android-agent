There is no real external calendar integration or external calendar availability; the built-in local calendar uses saved schedule blocks. Advanced habit analysis, emotional-support flows and ML remain future work. Calls, messages, alarms and navigation do not execute. Proactive checks require a separate explicit opt-in and Android notification access. The declared permissions are exactly POST_NOTIFICATIONS, RECORD_AUDIO and READ_CONTACTS. There is no INTERNET permission; no telemetry, training upload or automatic background behavioral collection is enabled.
