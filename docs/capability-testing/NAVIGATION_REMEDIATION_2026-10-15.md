# Navigation remediation from the failed capability v002 baseline

Date: 2026-10-15 (Asia/Calcutta). This is a new investigation record. The v002 baseline and v001 incident evidence remain unchanged. Capability implementation, ML work and physical-device testing remain stopped.

## Product behavior decision

**Current intended root: Agent/Chat.** This is an inference from the retained, paused UI change, not a new product approval. `Workspace.CHAT` maps to the Agent protocol destination; `ShellUiState` defaults to Agent/Chat; `ShellViewModel` restores invalid routes to Agent/Chat and sends the final Back there. `RequestViewModel` maps Agent submissions to Chat origin. These are coordinated behavior changes. The historical `UI_CONTRACT.md` lists five destinations without choosing a root, while `PHASE_3_VERIFICATION.md` explicitly described Today as the root and the old `ShellStateTest` and `NavigationShellTest` assert Today. The new code superseded that Phase 3 default, but the old test wording and verification prose had not been updated. The current shell still renders the old five-tab scaffold and an Agent empty state; it does not yet render all the new `Workspace` pages. That incomplete UI work is outside this remediation.

Before editing, the retained `ShellViewModel` changes explicitly replaced the default, unknown-route fallback, Back destination and `handlesBack` root from Today to Agent/Chat. `Workspace.kt` introduced Chat as the first workspace. The pre-change `HEAD` source and Phase 3 report consistently used Today. Therefore the two JVM failures were stale root assertions, while restored-route consistency also needed an implementation repair.

## JVM repair and result

`ShellViewModel` now derives a workspace from a legacy saved destination when no workspace was saved, and derives the legacy tab destination from a valid saved workspace. An invalid saved destination with no valid workspace lands on Agent/Chat. `handlesBack` also accounts for an open entity detail. The two affected `ShellStateTest` expectations now assert Agent/Chat. Their other checks still cover composer/privacy Back order, draft retention, unknown-route fallback and the 4,000 UTF-16-unit draft limit. A legacy saved Plan route is also asserted to restore as Plan workspace.

Both affected tests passed **individually**. The complete Debug JVM suite passed **141 tests, 0 failures, 0 skipped**. The complete Release JVM suite passed **141 tests, 0 failures, 0 skipped**. No unrelated JVM assertion was relaxed. `git diff --check` passed.
