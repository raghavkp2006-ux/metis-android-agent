# Raw artifacts

Store approved immutable source bytes and intake manifests locally. Hash exact
bytes before parsing. Directory payloads are ignored by Git; this README is tracked.
Plan 05 also stores generated structural plans and their hashed code/template
snapshots here, under a separate generation commit marker. These are internal
candidates. Plan 07 adds hashed MASSIVE 1.1 and CLINC150/OOS public-source bytes,
license evidence and acquisition observations. Public dev/test material remains
raw/protected; observations do not grant training approval. Legacy evidence remains in its original
immutable archive, never copied here by default.
