# METIS NLU Collection — Scenario Cards

**Purpose**: Each card describes a real-life situation in plain words. Read the
situation, then type what you would naturally say to METIS in that moment.
**Do not** copy or paraphrase any wording from this file — the goal is your own
natural phrasing.

## Contributor Quotas (per intent)

| Requirement | Target |
|---|---|
| Utterances per intent | **8 – 10** |
| Hinglish / code-mixed | ≥ 25 % |
| Typos / misspellings | ≥ 10 % |
| Voice-style (no punctuation, filler words OK) | ≥ 10 % |
| Multi-intent (one message, two goals) | ≥ 5 % |

**Privacy rule**: Use only fake names and fake numbers. Suggested fake names:
Aarav, Priya, Dev, Riya, Sam, Arjun, Sneha, Vikram, Ananya, Rohan.
Suggested fake phone numbers: 9876500000, 9123456789.
Never type real contacts, real numbers, real emails, or anyone else's personal information.

## Multi-Intent & Style Reminders

### Multi-Intent Contributions (≥ 5% quota)
When providing a multi-intent utterance, file the row under the **primary intent**
being requested, apply the `multi_intent` tag in `style_tags`, and briefly explain
the secondary intent in `notes`.
- *Example combinations*: Scheduling a new task while simultaneously demanding a timed alert;
  closing out a finished task while noting a commitment to an external party;
  updating a task title while shifting its priority rank;
  or requesting to dial a contact while queuing a follow-up text.

### Hinglish / Code-Mixed Contributions (≥ 25% quota)
Every intent card above must include natural Hinglish phrasing:
- Use Roman script (English alphabet), avoiding Devanagari characters.
- Blend Hindi vocabulary naturally (e.g., words like *aaj, kal, parso, abhi, jaldi, batao, kar do, hata do, dikhao, pending, kitna, kaunsa, nipatna*).
- Reflect the conversational tone of an undergraduate or working professional speaking casually.
